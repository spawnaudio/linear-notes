# A little room to think

A home for your notes, half-formed ideas, and things worth coming back to. Nothing between you and the page.

## Make yourself at home

Write naturally. Use **bold**, *italics*, or `a little code` when you need them. Markdown becomes a document as you type.

> [!NOTE] Yours, by default
> Every note is a plain Markdown file in this folder. Open it in another editor, back it up, or take it with you.

## Find your own rhythm

- [ ] Write down one idea
- [ ] Create a folder for something you care about
- [ ] Bookmark a note you want to keep close

> The first draft is just you telling yourself the story.

## A few useful things

Type `/` on an empty line for headings, lists, quotes, callouts, and more. Select a phrase for a small formatting toolbar.

[The document editor that inspired this space](<https://linear.app/docs/documents> "card")

Click a card once to select it. Click again when you’re ready to visit.
